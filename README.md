# OurVows - Wedding Planning Journal

Um aplicativo web minimalista para planejamento de casamentos no estilo bullet journal digital.

## 🎯 Proposta

O OurVows é um caderno digital de planejamento do casamento, criado para ajudar casais a organizar todos os aspectos do seu grande dia. Com uma estética clean e inspirada em bullet journals, oferece uma experiência íntima e funcional para controle de gastos, registro de fornecedores, timeline de tarefas e anotações livres.

## ✨ Características

### 📊 Dashboard
- Contagem regressiva até o casamento
- Visão geral do orçamento (total, gasto, restante)
- Indicadores de progresso do planejamento
- Estatísticas em tempo real

### 💰 Budget
- Controle completo de despesas
- Categorização por tipo de serviço
- Acompanhamento de valores previstos vs pagos
- Status das despesas (pago, pendente, parcelado)
- Cálculos automáticos de totais

### 👥 Vendors
- Cadastro completo de fornecedores
- Informações de contato detalhadas
- Valores acordados
- Anotações personalizadas
- Organização por tipo de serviço

### 📅 Timeline
- Linha do tempo visual do planejamento
- Tarefas organizadas por mês
- Status de acompanhamento (pendente, em andamento, concluído)
- Visualização cronológica

### 📝 Notes
- Área livre de anotações
- Estilo bullet journal com suporte para listas e checkboxes
- Diferentes tipos de notas (texto, checklist, ideias)
- Formatação automática de bullet points

### ✅ Checklist
- Checklist geral do casamento
- Organização por categorias
- Sistema de prioridades
- Acompanhamento de progresso
- Marcação de itens concluídos

## 🎨 Design

- **Estilo**: Minimalista e clean
- **Cores**: Neutras e suaves (bege, off-white, cinza claro)
- **Tipografia**: Playfair Display (títulos) e Inter (textos)
- **Interface**: Inspirada em bullet journals tradicionais
- **Experiência**: Íntima, organizada e emocional

## 🛠️ Tecnologias

- **HTML5**: Estrutura semântica
- **CSS3**: Design responsivo e animações
- **JavaScript Vanilla**: Funcionalidade completa
- **LocalStorage**: Persistência de dados local
- **Google Fonts**: Tipografia elegante

## 📱 Responsividade

O site é totalmente responsivo e funciona perfeitamente em:
- Desktop
- Tablets
- Smartphones

## 🚀 Como Usar

1. **Abra o arquivo `index.html`** no seu navegador
2. **Configure a data do casamento** no Dashboard
3. **Comece adicionando despesas** na seção Budget
4. **Cadastre seus fornecedores** na seção Vendors
5. **Organize sua timeline** com tarefas mensais
6. **Faça anotações livres** na seção Notes
7. **Acompanhe o checklist** geral do casamento

## 💾 Persistência de Dados

Todos os dados são salvos automaticamente no localStorage do navegador, garantindo que suas informações não sejam perdidas ao recarregar a página.

## 🎯 Público-Alvo

O OurVows foi desenvolvido para uso pessoal do casal, oferecendo uma experiência privada e organizada para o planejamento do casamento.
